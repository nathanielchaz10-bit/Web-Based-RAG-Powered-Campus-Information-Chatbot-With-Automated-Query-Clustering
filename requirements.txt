# --- Document ingestion pipeline (app/services/ingestion) ---
# pypdfium2: PDF text extraction + page rendering for OCR. Pure prebuilt wheels
# (PDFium) -- no compiler, no system dependency, works on Windows/Python 3.13.
# Pillow: image handling for rendered pages.
# python-docx: reads a .docx in body order so native Word tables can be rendered
#   as Markdown (docx2txt above is the fallback; it flattens tables).
#
# The default OCR backend is Gemini vision (reuses langchain-google-genai above,
# no extra package). The optional Tesseract fallback needs BOTH pytesseract
# (below) AND the Tesseract system binary, which pip cannot install:
#   Debian/Ubuntu: apt-get install tesseract-ocr
#   macOS:         brew install tesseract
#   Windows:       https://github.com/UB-Mannheim/tesseract/wiki
# Only install Tesseract if you intend to use the offline OCR backend.
#
# Force-OCR on a .docx renders it to PDF first via headless LibreOffice, another
# system dependency pip cannot install (optional -- without it, docx Force-OCR
# falls back to text + embedded-image OCR):
#   Debian/Ubuntu: apt-get install libreoffice
#   macOS:         brew install --cask libreoffice
pypdfium2==5.10.1
Pillow==10.4.0
pytesseract==0.3.13
python-docx==1.1.2
